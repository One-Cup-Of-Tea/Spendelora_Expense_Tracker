# Spendelora static prototype

Open `index.html` directly in any modern browser. A local server such as VS Code Live Server is optional, not required.

This is an HTML and CSS only visual prototype. The totals, chart, budget bars, expenses, form, and chat are hardcoded sample content for November 2026. The Add expense form and Ask Spendelora conversation are clearly marked previews; disabled controls do not save data, submit a form, or provide live AI responses.
